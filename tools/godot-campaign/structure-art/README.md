# Campaign structural kit (Blender source)

Eight original modular Blender shells are generated by `build.py` as editable `.blend` sources and exported as 16 compact GLBs (near/distant manual LOD). Rebuild using Blender 4.5.14:

```sh
LP_NUM_THREADS=1 /home/mojo/.tmp-on-disk/cocs-blender-toolchain/blender-4.5.14-linux-x64/blender -b -t 1 --python tools/godot-campaign/structure-art/build.py
```

`godot/campaign/structure_art.gd` loads imported geometry once per kit/LOD, batches repeated modules by material and 48 m cell, and fits every module within the original `arena.blocks` collision footprint. The structural geometry has no collision. Terrain build still makes exactly one authoritative `BoxShape3D` for **every** original block; only the corresponding plain non-rock box visual is replaced. Roofs and details are within the original top/footprint. Recessed service panels are **closed** rather than implied traversable doorways. No new bridge decks or route crossings are placed.

Style selection is deterministic from campaign index and named block IDs: Rootfall relay/outpost; Siltwake pump/abutment; Emberline refinery/uplink; Crown gate/receiver. Tall pumphouses, uplinks and receiver fins repeat capped 5 m maximum stories, with continuous opaque core, separated foundation courses and regional metal/stone accents. Near LOD has slatted vents and fasteners; far LOD retains profile, panel mass and specialized silhouettes. Each model uses four or five imported rough PBR material batches. Models and palettes are fully original and runtime Blender is unnecessary.

Verified with Godot 4.5.2:

```sh
LP_NUM_THREADS=1 Godot_v4.5.2-stable_linux.x86_64 --headless --path godot --editor --import --quit
LP_NUM_THREADS=1 Godot_v4.5.2-stable_linux.x86_64 --headless --path godot -s res://tests/campaign/structure_art.gd
LP_NUM_THREADS=1 Godot_v4.5.2-stable_linux.x86_64 --headless --path godot -s res://tests/campaign/terrain.gd
```

Per-map block / rendered module / material-and-chunk draw-batch budgets (both LODs allocated, only one visible by range): Rootfall 25 / 25 / 96; Siltwake 34 / 54 / 104; Emberline 40 / 70 / 128; Crown 37 / 82 / 130. Both LOD source meshes together are 10.9–11.7k triangles per map (shared geometry; instanced). The Godot test verifies imported world-up bounds within normalized collision footprint and top, opaque material roughness, triangle/draw budget, and unchanged collider counts.

Matched terrain-camera render evidence, five views for each of four maps, is at `/home/mojo/.tmp-on-disk/cocs-campaign-evidence-20260930/blender-world/structures/{before,after}/`. The intermediate failed axis-conversion renders are preserved in `failed-axis-render/`.
