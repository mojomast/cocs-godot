# Campaign structural kit (Blender source)

Eight original modular Blender families are generated by `build.py` as editable `.blend` sources and exported as 40 compact GLBs (near/distant manual LOD and base/shaft/top profiles for the six taller families). Rebuild using Blender 4.5.14:

```sh
LP_NUM_THREADS=1 /home/mojo/.tmp-on-disk/cocs-blender-toolchain/blender-4.5.14-linux-x64/blender -b -t 1 --python tools/godot-campaign/structure-art/build.py
```

`godot/campaign/structure_art.gd` loads imported geometry once per kit/LOD, batches repeated modules by material and 48 m cell, and fits every module within the original `arena.blocks` collision footprint. The structural geometry has no collision. Terrain build still makes exactly one authoritative `BoxShape3D` for **every** original block; only the corresponding plain non-rock box visual is replaced. Roofs and details are within the original top/footprint. Recessed service panels are **closed** rather than implied traversable doorways. No new bridge decks or route crossings are placed.

Style selection is deterministic from campaign index and named block IDs: Rootfall relay/outpost; Siltwake pump/abutment; Emberline refinery/uplink; Crown gate/receiver. Structural silhouettes and attached functional components are specific to each: mast socket and winding, pitched cabin hood, twin cylindrical impellers and pipe risers, coursed inclined flood buttress, external heat-exchanger bank, radiator vanes, hexagonal receiver spine, and reinforced sealed gate jamb. Tall blocks have a ground footing only on their base, continuous vertical shaft supports, and a roof termination only on the final story (each story at most 5 m). Near LOD adds fittings and fasteners; far LOD retains the specialized profile. Each model uses four or five imported rough PBR material batches. Models and palettes are fully original and runtime Blender is unnecessary.

Verified with Godot 4.5.2:

```sh
LP_NUM_THREADS=1 Godot_v4.5.2-stable_linux.x86_64 --headless --path godot --editor --import --quit
LP_NUM_THREADS=1 Godot_v4.5.2-stable_linux.x86_64 --headless --path godot -s res://tests/campaign/structure_art.gd
LP_NUM_THREADS=1 Godot_v4.5.2-stable_linux.x86_64 --headless --path godot -s res://tests/campaign/terrain.gd
```

The Godot test verifies imported world-up bounds within normalized collision footprint and top, opaque material roughness, triangle/draw budget, and unchanged collider counts. Batch and source-triangle metrics are printed by that test after the regenerated GLBs are imported.

Matched terrain-camera render evidence from the first kit, five views for each of four maps, is at `/home/mojo/.tmp-on-disk/cocs-campaign-evidence-20260930/blender-world/structures/{before,after}/`. The revised family-specific kit requires a fresh Godot import and recapture before those `after/` images represent this source; the intermediate failed axis-conversion renders are preserved in `failed-axis-render/`.
