# Campaign structural kit (Blender source)

Eight original modular Blender families are generated by `build.py` as editable `.blend` sources and exported as 40 compact GLBs (near/distant manual LOD and base/shaft/top profiles for the six taller families). Rebuild using Blender 4.5.14:

```sh
LP_NUM_THREADS=1 /home/mojo/.tmp-on-disk/cocs-blender-toolchain/blender-4.5.14-linux-x64/blender -b -t 1 --python tools/godot-campaign/structure-art/build.py
```

`godot/campaign/structure_art.gd` loads imported geometry once per kit/LOD, batches repeated modules by material and 48 m cell, and fits every module within the original `arena.blocks` collision footprint. The structural geometry has no collision. Terrain build still makes exactly one authoritative `BoxShape3D` for **every** original block; only the corresponding plain non-rock box visual is replaced. Foundation bottoms are fitted to the lowest of nine terrain samples across each blocked footprint (including corners and edge midpoints), with a 0.25 m closed skirt clamped inside `baseY`; their tops remain exactly at the authoritative block top. Roofs and details are within the original top/footprint. Recessed service panels are **closed** rather than implied traversable doorways. No new bridge decks or route crossings are placed.

Style selection is deterministic from campaign index and named block IDs: Rootfall relay/outpost; Siltwake pump/abutment; Emberline refinery/uplink; Crown gate/receiver. Structural silhouettes and attached functional components are specific to each: mast socket and winding, pitched cabin hood, twin cylindrical impellers and pipe risers, coursed inclined flood buttress, external heat-exchanger bank, radiator vanes, hexagonal receiver spine, and reinforced sealed gate jamb. Tall blocks have a ground footing only on their base, a continuous opaque 0–1 inner load core behind the authored exterior courses at every story boundary, vertical shaft supports, and a roof termination only on the final story (each story at most 5 m). Both approach-facing elevations and side load systems carry legible detail. Near LOD adds fittings and fasteners; far LOD retains the specialized profile. Each model uses three to five imported rough PBR material batches, with Godot's redundant automatic mesh LOD/shadow mesh generation disabled by the `.glb.import` presets. Models and palettes are fully original and runtime Blender is unnecessary.

`python3 tools/godot-campaign/structure-art/verify_profiles.py` audits all four actual generated recipes without launching Godot. It reconstructs block exposure, asserts every required profile/LOD export exists, checks the forest-only single-shell contract, and counts source triangles and material/chunk draw batches. Current static recipe results (blocks / segments / two-LOD material batches / loaded source triangles): Rootfall 25 / 25 / 96 / 8868; Siltwake 34 / 54 / 182 / 22432; Emberline 40 / 70 / 224 / 27240; Crown 37 / 83 / 204 / 28992. Only one LOD band is visible by range. The Godot test additionally verifies imported world-up bounds within normalized collision footprint and top, the continuous structural core across adjacent segments, footing below all nine footprint samples, opaque material roughness, triangle/draw budget, and unchanged collider counts. More geometry is retained on both directional faces, so structures remain legible from either route approach. The combined campaign environment-art and terrain regressions passed with the integrated biome decorator before the final structural-footing recapture.
