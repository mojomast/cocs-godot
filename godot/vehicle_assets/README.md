# Fleet authored visual attachments

Optional generated `puma`, `titan`, `scout` GLBs, three explicit distance LODs.
Current checkout contains authoring source only. No Blender output is claimed.
See `port/expansion-four/vehicles/` for source contracts and queued acceptance.

The adapter validates all rigid attachment names before hiding procedural meshes.
Missing/incomplete assets retain the existing native presentation. Imported assets
contain no native physics, collision, skeletal animation or authoritative scripts.
