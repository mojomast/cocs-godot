# Local menu bot seats

The local native Deathmatch and identity-zone Domination authorities accept `config.botCount` up to **24**, with exactly one human actor (25 total). The authority constructor also accepts `bots` as an alias for `botCount` and `roundSeconds` as an alias for `timeLimit`; WebSocket `host.config` uses `botCount`, `timeLimit`, `fragLimit`, `difficulty`, and `mode`. Deathmatch allows 1–24 bots; identity-zone Domination allows 0–24. Map and mode remain fixed to their reviewed routes. Invalid counts are rejected, never silently clamped.

This is a **route-scoped extension**, not a change to the source's ordinary config rule. `game/config.mjs` still normalizes Deathmatch/Domination to at most 8 bots, and `game/core.mjs` still caps total actors at 32. The local constructor intercepts its own config assignment before actor creation, verifies the source-normalized count, and installs the validated requested count. Every bot is then built by the source `Match` constructor. Large rosters receive bounded walkable initial/respawn placement near authored anchors; the 24-startup test checks actual 25-seat actor and snapshot counts, bot AI state, separation and support, plus the outbound snapshot frame bound. Ordinary <=8-bot match spawning remains source-owned. The shared debug-frame parser remains limited to 0–8 on other routes; a route-scoped validating adapter permits Deathmatch debug 1–24 and Domination debug 0–24. A launch selected at 24 retains its real roster when other live debug overrides are applied.

Focused lightweight verification: `node --test port/native-menu-debug-bots/tests/startup.test.mjs` and then `node --test port/native-menu-debug-bots/tests/debug-24.test.mjs`. After integration, the lead can run the full authority suites **serially**, then a separately scheduled Godot import/smoke and performance run: `node --test port/native-arenas/tests/*.test.mjs`, `node --test port/native-identity-zones/tests/*.test.mjs`. These full suites are intentionally not part of the concurrent lane's verification.
