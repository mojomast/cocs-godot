# Audiovisual integration record

The requested composition hooks are now applied, not left as instructions.

* `world/session.gd` binds `res://audio/av_service.gd` before the first start/snapshot/event, keys rounds by endpoint + room + public `roundRevision`, and routes fresh snapshots, results, focus, transport, settings overlay and authoritative events. Same-round reconnect preserves event latches; the parent vehicle bridge remains intact.
* Horde, LATTICE, Zone Modes, Assault, Arms Race, standalone Objectives, native Deathmatch and identity Domination use the shared-session hooks in their overridden callbacks. Sports and Combined Arms use `sports/av_lifecycle.gd` for their independent networks. Home has menu score on user gesture and focus/mute controls. Cinderwake's existing transit horn is routed through Effects without another horn being generated.
* Existing `PortAudioFeedback` retains ordinary combat ownership; its eight voices now use the Effects bus and respond immediately to local settings/CLI mute. New mounted foley and objective earcons use separately bounded pools. Master remains the sole bus parent. Mute discards events rather than queuing a replay burst.
* `godot/audio/outcome.gd` reads explicit team/race winners and source ranking fields, never infers a spectator loss. Race/soccer countdown 3-2-1-GO is edge-detected from `state.race`; the first midrace snapshot does not invent GO. Final-ten warning latches once per genuine round.
* `godot/ambience/weather_service.gd` reads authoritative `state.singleplayer.weather/timeOfDay` (the lowercase key in `game/core.mjs`), not top-level weather. It uses source arena metadata and clock. Its ownership handshake suppresses only overlapping falling ice/motes; native architectural ambience persists and weather-off restores original fields.
* Music includes source 32-bar D-minor motif/chords, all authored mode/biome palette keys, race/soccer percussion variants, bounded Ogg sample voices and the only delivered Moth ritual bed. This is a source-derived native arrangement, not a bit-exact Web Audio synth or a complete 172-sample bank.

**Focused serial-slot checks:** import/runtime parse, real ALSA-null AudioServer DSP PCM variation, same-state weather render, source-vector routing, event/reconnect dedupe, long-round bounded resources, rapid Home lifetime, three-family Horde recipe binding, and selected real-scene journeys passed. ALSA-null proves native DSP output, **not** hardware audibility or human listening. Parent still owns aggregate packaging/export and Windows playback; no source game/server/public audio asset was changed.
