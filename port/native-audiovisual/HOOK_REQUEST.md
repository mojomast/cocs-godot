# Audiovisual composition request (apply after Vehicle/Objective ownership lands)

`res://audio/av_service.gd` composes the new `godot/audio` score/announcer, four-voice objective earcons, four-voice mounted vehicle foley, and `godot/ambience` weather. It does not subscribe to the network or mutate authority. Add it to the owning session only once. **Do not copy a second ordinary shot/launch/hurt/pickup/explosion path**: `PortCombatFeedback.audio_feedback` already owns those eight pooled voices. Cinderwake transit horn remains owned by its existing Horde map; only route its bus to Effects if appropriate.

1. On playable session setup (shared `world/session.gd` plus independently composed Horde/LATTICE routes), `var av := preload("res://audio/av_service.gd").new(); add_child(av)`, then `av.bind_session(self, world.camera, arena_source_metadata, selected_mode, public_round_identity, deterministic_seed)`. Pass the arena dictionary returned by the existing source catalog, not a made-up map. Register `LocalSettings.audio_preferences_changed.connect(av.apply_settings)` once and immediately call `av.apply_settings(LocalSettings.values)`. `--mute`/`--mute-capture` override the new service internally; apply the same override to old `PortAudioFeedback` as well. All its players descend from Master without multiplying Master twice. If audio does not unlock before a user gesture, call `av.music.start()` then (not from autoplay).
2. In each `client.started` callback call `av.start_round(public_round_identity)`; it is a no-op if identity is unchanged. Native `round_starts` is a local counter, not proof against reconnect. Prefer public `roundRevision` alongside server match identity (`frame.roundRevision` exists in native transport), or a monotonic start generation when explicitly starting a new Horde run; Horde `inputEpoch` is NOT a round key. On replay seek call `av.seek_reset(identity)`. Do not clear same-round event IDs on dropped transport, focus, actor-seat changes, or `CombatFeedback.clear_round()`.
3. In the existing `client.events` listener, after applying combat effects, call `av.apply_events(items)`. Horde wire `id` is the only dedupe identity; `sourceId`/payload ordinal is provenance, not identity. Before first snapshot the router consumes IDs but drops unknown-recipient sound rather than using a stale seat. The LATTICE routing table requires a valid local team for private economy/order events; spectators without team get only public world events. Never infer a private fact from an event lacking a team.
4. On each fresh snapshot call `av.apply_snapshot(frame.state, client.actor_id, not snapshot_watch.stale())` and per presentation frame `av.tick(delta)`. It reads actor HP/vehicle and `singlePlayer.weather/timeOfDay` only where actually present; top-level `weather` is not authoritative. The owner must supply additional public world intensity, team/score count/race countdown context; **not implemented here**. On `results`, compute outcome only from explicit winner data (team for team modes/soccer/LATTICE, actor for race/FFA) and call `av.finish("victory" | "defeat" | "neutral")`; unknown/spectator must not default to defeat. Results scene owns the score until a new round; do not let combat polling overwrite it. Observe race countdown public `state.race`, including soccer, but never synthesize a GO for midrace join.
5. On stale snapshot (> existing freshness guard), focus loss, settings overlay and transport disconnection call `av.suspend(reason)` / `av.set_focus(false)` and discard incoming muted events. Recovery calls `av.set_focus(true)`, a current snapshot, then only fresh events (no backlog). Existing effect system handles its own clearing. Route `effects_volume` to existing `PortAudioFeedback` pooled voices in its owner (or bus), not another feedback synthesizer. A separate `Effects` bus makes this and the Cinderwake horn straightforward; all buses descend from Master. Weather precipitation is opt-in until native fields/Moth motes are suppressed per `tools/godot-audiovisual/weather-integration.md`; acknowledge with `av.weather.set_native_weather_suppressed(true)`.
6. The native asset manifest and notices in `godot/audio` must be included by export presets as original local Ogg/WAV bytes; no HTTP fetch. Parent owns package/export/probes and Windows acceptance. Read status dictionaries for loaded streams/durations/loop boundaries, active voices, dropped/duplicate events, last cue, weather seed/particle/thunder and suspension reason.

The canonical router is `godot/audio/event_router.gd`. A mere test of its semantic plans is **not evidence that the composition is wired or audible**. Existing voices and map atmosphere need the session hooks above. No claim of Windows playback or audio mix is made until parent's serial engine/render/export probes run.
