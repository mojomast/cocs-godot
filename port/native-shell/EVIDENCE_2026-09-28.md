## Defects found and corrected during verification

1. Disposable packaged/development route XDG paths would discard settings.
   Supervisors now propagate a separate stable absolute preference path.
2. Bare autoload identifiers fail while standalone SceneTree contracts preload
   route scripts. A small dynamic accessor resolves the real settings singleton,
   with deterministic defaults for detached fixtures.
3. Fixed project stretch dimensions concealed compact layouts. Interface scaling
   now uses the actual window as its basis; contracts drive real logical sizes.
4. Home and command-deck minimum widths/heights overflowed large UI scales.
   Responsive stacking, wrapping, vertical scroll and focus-following corrected
   those surfaces.
5. First-open live REQ content briefly expanded the deck beyond the viewport even
   after synthetic resize checks passed. Live-population layout recovery and a
   source-driven first-open bounds assertion cover the actual failure.
6. The guest fixture initially expected immediate peer removal and one total
   room. It now observes source reconnect grace and the built-in default room
   instead of assuming native-specific authority behavior.
7. Static review found that canvas scaling also scales Godot's `relative` mouse
   motion. Shared unscaled motion handling keeps aim independent of UI scale,
   including the preview camera routes. Release events must also continue
   reaching input-latch observers while Settings is open so controls do not
   remain blocked after a physical release.
8. The first aggregate stopped at benchmark autostart: its `controls_seconds`
   counter included unmeasured warm-up time, so a healthy, continuously
   controllable actor could exceed the measured window. The counter now excludes
   warm-up. Regression coverage pins that accounting and the existing validator
   bound; the bound was not widened. The failed attempt is preserved under
   `.port-runtime/verification-attempts/shell-b53182de-benchmark-duration/` in the
   validation worktree.
9. Rendered narrow-HUD review found the effects shortcut drawing across the
   mission card. LATTICE now keeps that shortcut hidden while preserving the
   explicit F10 metrics view. Objective guidance also prefers the current
   recipient's source label, matching the list and selected-target heading.
