# All-maps test preview — 2026-10-04 (follow-up exposure build)

The user could not find Vesper Viaduct, Abyssal Pressureworks or Stormglass
Causeway in the first preview's menus. They were shipped in data but absent from
the launcher allowlist and the `Multiplayer Worlds` route. This follow-up exposes
all six authored worlds for testing.

## Source change

**`b58e312b`** (on `feature/relay-campaign`) adds the three worlds to:

- `tools/godot-package/options.mjs` and `tools/godot-dev/launch_options.mjs`
  (packaged and dev launcher allowlists),
- `tools/godot-package/routes_meta.mjs` (menu names, map values, per-map modes;
  description corrected from "Seven" to "Ten authored source-backed worlds"),
- regenerated `godot/ui/routes.json` (26 routes; route-parity capability checks pass).

Mode lists match `godot/multiplayer_worlds/catalog.gd`:

| Map | Modes | Scene |
|---|---|---|
| Vesper Viaduct | deathmatch, teamdeathmatch, CTF, domination, KOTH, uplink | demo |
| Abyssal Pressureworks | deathmatch, teamdeathmatch, CTF, KOTH, domination, holdout | demo |
| Stormglass Causeway | puma-race | sports_demo |

Vesper's native stair step-up caveat remains; the exposure is for testing only.

## Verification

- `gen_routes --check` and the route/world/expansion/staged/promoted tests passed
  after the exposure edits (targeted rerun; see below for two pre-existing
  full-suite harness failures unrelated to this change).
- Fresh extraction + `manifest_validation.mjs` passed on both archives at
  candidate `b58e312b`.
- Bounded packaged-launcher runs on the Linux extraction (`DISPLAY` Xvfb,
  terminated by timeout as expected):
  - `vesper-viaduct/deathmatch` → `demo.tscn`, authority ready, native started;
  - `abyssal-pressureworks/deathmatch` → `demo.tscn`, same;
  - `stormglass-causeway/puma-race` → `sports_demo.tscn`, same.
  All three logs contain zero script/parse errors; the only error line is the
  headless ALSA fallback to the dummy audio driver.
- Public asset URLs return HTTP 200 with the exact sizes above.
- **Windows CI run [37210288551](https://github.com/mojomast/cocs-godot/actions/runs/37210288551)
  completed successfully** against the published tag and candidate `b58e312b`
  (2026-10-04T14:43:02Z → 14:59:33Z): bundled runtimes, expansion mode pairs
  including `vesper-viaduct`, `abyssal-pressureworks` and `stormglass-causeway`,
  native cases with cleanup, and resource checks all passed with artifacts retained.
