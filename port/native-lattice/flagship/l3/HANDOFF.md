It sends **no frame**. Setup distinguishes requests from echoes, host from guest; start disabled absent echo/host-wait. A result cannot retain command authority.
- `godot/lattice/world_commands.gd`: `bind_authored_map(map_id, source_map)` reuses L2 topology for selected legality/supply, while HOLD remains transport-authorized. Existing Fighter/REINFORCE gates and per-purchase consent remain. Receipts explicitly distinguish queued, accepted, settled, rejected/replaced; settlement is not capture or spawn evidence.
- `godot/lattice/world_telemetry.gd`: bounded in-memory trace (128 records / 32 recent events). Order-complete correlation requires exact `cardId`, source `peerId` equal to the local peer passed by the caller, action `roundRev` equal to current projection revision, and event arrival within that telemetry revision's window. `game/cocs.mjs` events carry `cardId`, `peerId`, `contributors`, `node`, and `team` (plus wrapper `id`/`tick`), but no `peer`, `actor`, or `round`; no such fields are invented. Contributors are separate actor evidence, not required to link the issuer effect. `effect_for_action` gates the positive command-history effect. Capture participation remains separate, nearby/unattributed evidence; economy deltas are not card causality.
- `godot/tests/lattice/flagship_l3_roles_contract.gd` synthetic legal-pair and caveat fixture (unrun); `godot/tests/lattice/flagship_l3_evidence_contract.gd` source-shaped event, false-correlation, boundary, and buffer-cap fixture (unrun); `godot/tests/lattice/flagship_l3_contract.mjs` lightweight source/API static contract.
